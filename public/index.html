Source: HubSpot DEAL records, amounts in company currency (USD), pulled server-side through this app's own HubSpot Private App connection. Stalled = HubSpot's hs_is_stalled flag (time in current stage running ≥20% longer than the deal owner's typical closed–won pace for that stage). Weighted pipeline = open deal value × the stage's win probability.

Click Refresh from HubSpot to re-run the pull live. If a section can't refresh, it keeps showing its last successful pull rather than going blank. This page also refreshes itself once automatically when it first loads.

Shared with everyone: unlike a personal HubSpot login, this dashboard always queries HubSpot with the same server-side connection, so every viewer sees identical numbers — there's no per-person permission variation.

Week-over-week: HubSpot only ever reports the current state of a deal, so the "vs last week" lines under Open Pipeline Value, Weighted Pipeline and Stalled Deals are built by this app, not pulled from HubSpot — every successful refresh saves a dated snapshot, and once one exists from ~a week back the comparison appears automatically. Expect "no history yet" for the first several days after this goes live.
